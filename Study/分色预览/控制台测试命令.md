# 控制台测试命令

## 📋 请按顺序执行以下命令

### 1️⃣ 清除控制台并重新加载

```javascript
console.clear();
location.reload();
```

### 2️⃣ 等待PDF加载完成后，查看evaluator.js的日志

在控制台过滤器中输入：

```
DEBUG] setFillColor
```

应该能看到类似这样的日志：

```
[DEBUG] setFillColor: colorSpace=DeviceCMYK, args=[1,0,0,0]
[DEBUG] setFillColor: Creating CMYK ColorValue
[DEBUG] Created CMYK ColorValue: [1,0,0,0] → RGB=#00ffff
```

**如果没有看到这些日志，说明：**

- 那些CMYK颜色不是通过setFillColor设置的
- 可能是Separation色彩空间或其他方式

### 3️⃣ 展开channels对象

在控制台中，当看到：

```
[DEBUG canvas.js] setFillRGBColor received ColorValue: {colorSpace: 'CMYK', channels: {…}, ...}
```

点击`{…}`展开，查看实际的CMYK值。应该类似：

```javascript
channels: {
  cmyk: [1, 0, 0, 0]; // 这是Cyan 100%
}
```

### 4️⃣ 手动测试ColorValue转换

在控制台输入以下代码，测试ColorConverter：

```javascript
// 测试1: Cyan 100%
const cyan = [1, 0, 0, 0];
const r1 = 255 * (1 - cyan[0]) * (1 - cyan[3]);
const g1 = 255 * (1 - cyan[1]) * (1 - cyan[3]);
const b1 = 255 * (1 - cyan[2]) * (1 - cyan[3]);
const hex1 =
  "#" +
  [r1, g1, b1].map(x => Math.round(x).toString(16).padStart(2, "0")).join("");
console.log(`Cyan [1,0,0,0] → RGB(${r1}, ${g1}, ${b1}) → ${hex1}`);

// 测试2: Magenta 100%
const magenta = [0, 1, 0, 0];
const r2 = 255 * (1 - magenta[0]) * (1 - magenta[3]);
const g2 = 255 * (1 - magenta[1]) * (1 - magenta[3]);
const b2 = 255 * (1 - magenta[2]) * (1 - magenta[3]);
const hex2 =
  "#" +
  [r2, g2, b2].map(x => Math.round(x).toString(16).padStart(2, "0")).join("");
console.log(`Magenta [0,1,0,0] → RGB(${r2}, ${g2}, ${b2}) → ${hex2}`);

// 测试3: Yellow 100%
const yellow = [0, 0, 1, 0];
const r3 = 255 * (1 - yellow[0]) * (1 - yellow[3]);
const g3 = 255 * (1 - yellow[1]) * (1 - yellow[3]);
const b3 = 255 * (1 - yellow[2]) * (1 - yellow[3]);
const hex3 =
  "#" +
  [r3, g3, b3].map(x => Math.round(x).toString(16).padStart(2, "0")).join("");
console.log(`Yellow [0,0,1,0] → RGB(${r3}, ${g3}, ${b3}) → ${hex3}`);

// 测试4: Black 100%
const black = [0, 0, 0, 1];
const r4 = 255 * (1 - black[0]) * (1 - black[3]);
const g4 = 255 * (1 - black[1]) * (1 - black[3]);
const b4 = 255 * (1 - black[2]) * (1 - black[3]);

  "#" +

console.log(`Black [0,0,0,1] → RGB(${r4}, ${g4}, ${b4}) → ${hex4}`);
```

**预期输出**:

```
Cyan [1,0,0,0] → RGB(0, 255, 255) → #00ffff
Magenta [0,1,0,0] → RGB(255, 0, 255) → #ff00ff
Yellow [0,0,1,0] → RGB(255, 255, 0) → #ffff00
Black [0,0,0,1] → RGB(0, 0, 0) → #000000
```

### 5️⃣ 检查PDF中的实际CMYK值

我需要知道PDF中定义的CMYK值是多少。请在控制台中查找包含"args="的日志：

```
[DEBUG] setFillColor: colorSpace=DeviceCMYK, args=[?,?,?,?]
```

这会告诉我们PDF文件中实际定义的CMYK值。

## 🤔 关键问题

从您之前的日志，我看到：

- `rgbFallback: '#ffffff'` - 白色
- `rgbFallback: '#000000'` - 黑色
- `rgbFallback: '#00ffff'` - 青色 ✅ 这是正确的Cyan
- `rgbFallback: '#ff00ff'` - 洋红 ✅ 这是正确的Magenta
- `rgbFallback: '#ffff00'` - 黄色 ✅ 这是正确的Yellow

**如果这些颜色是正确的，但您看到的显示不正确，可能的原因：**

1. **PDF中的CMYK值本身就不对** - 需要查看`args=`的值
2. **显示器色彩配置** - RGB #00ffff在不同显示器上看起来可能不同
3. **Separation色彩空间的混合** - 那些"Using old RGB logic"的颜色可能有问题
