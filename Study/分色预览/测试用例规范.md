### TC02: CMYK Lighten混合模式 (关键测试)

**优先级**: P0 (核心问题验证)  
**测试目标**: 验证CMYK空间Lighten混合正确性

**测试数据**:

```
图层1: 100% Black, CMYK [0, 0, 0, 1.0] → RGB #000000
图层2: 100% Cyan, CMYK [1.0, 0, 0, 0] → RGB #00FFFF
混合模式: Lighten
透明度: Alpha = 1.0
```

**预期结果**:

```javascript
// CMYK空间Lighten算法
function cmykLighten(c1, c2) {
  return [
    Math.min(c1[0], c2[0]),  // C: min(0, 1.0) = 0
    Math.min(c1[1], c2[1]),  // M: min(0, 0) = 0
    Math.min(c1[2], c2[2]),  // Y: min(0, 0) = 0
    Math.min(c1[3], c2[3])   // K: min(1.0, 0) = 0
  ];
}

结果: CMYK [0, 0, 0, 0] → 白色 ✅
```

**当前结果** (错误):

```javascript
// RGB空间Lighten算法
max(#000000, #00FFFF) = #00FFFF → 青色 ❌
```

**验收标准**:

- 最终渲染结果为白色
- 色值误差 < 1% (允许转换误差)
- 颜色空间记录为CMYK

**样本文件**: `test/pdfs/cmyk_lighten_test.pdf` (待创建)

### 性能测试脚本

```javascript
// test/performance/rendering_perf.mjs
async function measureRenderingPerformance(pdfPath, iterations = 100) {
  const times = [];
  const memoryUsages = [];

  for (let i = 0; i < iterations; i++) {
    const startMemory = performance.memory.usedJSHeapSize;
    const startTime = performance.now();

    await renderPDF(pdfPath);

    const endTime = performance.now();
    const endMemory = performance.memory.usedJSHeapSize;

    times.push(endTime - startTime);
    memoryUsages.push(endMemory - startMemory);
  }

  return {
    avgTime: average(times),
    p95Time: percentile(times, 95),
    avgMemory: average(memoryUsages),
    maxMemory: Math.max(...memoryUsages),
  };
}
```

```python
# tools/generate_test_pdf.py
from reportlab.pdfgen import canvas
from reportlab.lib.colors import CMYKColor

def create_cmyk_lighten_test():
    """生成TC02测试PDF"""
    c = canvas.Canvas("test/pdfs/cmyk_lighten_test.pdf")

    # 图层1: 100% Black

    c.rect(0, 0, 200, 200, fill=1)

    # 图层2: 100% Cyan, Lighten模式
    c.saveState()
    c.setFillColor(CMYKColor(1.0, 0, 0, 0))
    c.setBlendMode('Lighten')
    c.rect(0, 0, 200, 200, fill=1)
    c.restoreState()

    c.save()
```

### 颜色比较工具

```javascript
// tools/color_compare.mjs
export function compareColors(actual, expected, tolerance = 0.01) {
  const diff = Math.abs(actual - expected);
  return {
    match: diff <= tolerance,
    difference: diff,
    percentage: (diff / expected) * 100,
  };
}
```
