1. CMYK颜色过早转换为RGB，丢失通道信息

```javascript
// CMYK是减色系统：值越小越亮
function cmykLighten(back, src) {
  return [
    Math.min(back[0], src[0]), // C: 取最小值（最亮）
    Math.min(back[1], src[1]), // M
    Math.min(back[2], src[2]), // Y
    Math.min(back[3], src[3]), // K
  ];
}

// 测试：100%K + 100%C Lighten
// back = [0, 0, 0, 1.0], src = [1.0, 0, 0, 0]
// result = [0, 0, 0, 0] → 白色 ✅
```

## 技术成就

### 1. 零RGB强制转换 ✅

**问题**: 原实现在解析阶段就将CMYK转换为RGB，导致：

- CMYK通道信息丢失
- 无法在CMYK空间进行混合
- 混合模式语义错误

**解决方案**:

- 在evaluator.js中保留CMYK原始值
- 使用ColorValue封装颜色信息
- 仅在canvas.js渲染时转换为RGB
- 中间过程完全无RGB转换

**验证**:

```javascript
// 数据流
PDF: K 0 0 0 1 (100% Black)
  ↓ evaluator.js
ColorValue{colorSpace:'CMYK', channels:{cmyk:[0,0,0,1]}}  // ✅ CMYK保留
  ↓ OperatorList
{fn: OPS.setFillCMYKColor, args: [ColorValue]}  // ✅ 不转换
  ↓ canvas.js
this.current.fillColorValue = ColorValue  // ✅ 信息保留
this.ctx.fillStyle = ColorValue.toRGB() = "#000000"  // ✅ 仅渲染时转换
```

---

### 2. DeviceN完整支持 ✅

**问题**: 原实现将DeviceN转换为基础颜色空间，导致：

- 专色通道信息完全丢失
- 无法单独预览专色（如Spot1、Spot2）
- 无法实现专业预览功能

**解决方案**:

- 在colorspace.js中保存channelNames
- 在evaluator.js中创建DeviceN ColorValue
- 支持任意数量专色通道
- 提供通道分离/合并功能

**验证**:

```javascript
// DeviceN: [Cyan, Magenta, Yellow, Black, Spot1, Spot2]
const colorValue = ColorValueBuilder.createDeviceN(
  ["Cyan", "Magenta", "Yellow", "Black", "Spot1", "Spot2"],
  [0.5, 0, 0, 0, 0.8, 0.3]
);

colorValue.getCMYK(); // [0.5, 0, 0, 0] ✅
colorValue.getSpot("Spot1"); // 0.8 ✅
colorValue.getSpot("Spot2"); // 0.3 ✅

// 通道分离
const channels = channelManager.separateChannels(colorValue);
channels.get("Cyan"); // 0.5 ✅
channels.get("Spot1"); // 0.8 ✅
channels.get("Spot2"); // 0.3 ✅
```

### 3. 通道级独立混合 ✅

**问题**: 原实现在RGB空间混合，导致：

- CMYK Lighten结果错误（100%K + 100%C → 青色而非白色）
- DeviceN专色通道无法独立处理
- 混合语义与PDF标准不符

**解决方案**:

- 实现CMYK空间混合算法（取补色规则）
- 实现DeviceN空间通道级混合
- BlendModeFactory根据颜色空间选择算法

**验证 - CMYK Lighten**:

```javascript
const back = ColorValueBuilder.createCMYK([0, 0, 0, 1.0]); // 100% Black
const src = ColorValueBuilder.createCMYK([1.0, 0, 0, 0]); // 100% Cyan

const blendMode = BlendModeFactory.create("Lighten", "CMYK");
const result = blendMode.blend(back, src, 1.0);

result.getCMYK(); // [0, 0, 0, 0] ✅
result.toRGB(); // "#FFFFFF" (白色) ✅
```

**验证 - DeviceN通道独立**:

```javascript
const back = ColorValueBuilder.createDeviceN(["Cyan", "Spot1"], [0.8, 0.3]);
const src = ColorValueBuilder.createDeviceN(["Cyan", "Spot1"], [0.5, 0.7]);

const blendMode = BlendModeFactory.create("Lighten", "DeviceN");
const result = blendMode.blend(back, src, 1.0);

// 每个通道独立混合
result.getCMYK()[0]; // min(0.8, 0.5) = 0.5 ✅
result.getSpot("Spot1"); // min(0.3, 0.7) = 0.3 ✅
```
