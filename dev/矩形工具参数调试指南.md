# 矩形工具参数调试指南

## 问题描述

用户设置了颜色（红色）、粗细、透明度，但绘制的矩形仍然是黑色，参数没有生效。

## 已添加的调试日志

### 1. annotation_editor_params.js

- 检查 DOM 元素是否正确获取
- 监控参数事件派发

### 2. tools.js (AnnotationEditorUIManager)

- 监控 updateParams 调用
- 显示是否有选中的编辑器
- 显示更新的编辑器类型

### 3. draw.js (DrawingEditor)

- 监控 updateDefaultParams 调用
- 显示参数类型映射
- 显示更新后的默认选项

## 调试步骤

### 步骤 1: 打开浏览器控制台

1. 刷新页面（让 webpack 重新编译）
2. 打开浏览器开发者工具（F12）
3. 切换到 Console 标签

### 步骤 2: 检查初始化

页面加载后，应该看到：

```
[DEBUG] 几何工具参数元素状态: {
  editorGeoShapeColor: <input>,
  editorGeoShapeThickness: <input>,
  editorGeoShapeOpacity: <input>
}
```

**如果看到 `undefined`**，说明 DOM 元素未找到，需要检查：

- HTML 中的元素 ID 是否正确
- 元素是否在 viewer.js 中正确引用

### 步骤 3: 测试参数调整

1. 点击几何工具按钮
2. 调整颜色为红色（#ff0000）

应该看到：

```
[DEBUG] 派发参数事件: RECTANGLE_COLOR #ff0000 类型: 51
[DEBUG] UIManager.updateParams: {
  type: 51,
  value: "#ff0000",
  hasSelection: false,
  ...
}
[DEBUG] 更新默认参数，编辑器类型: ["RectangleEditor", ...]
[DEBUG] DrawingEditor.updateDefaultParams: {
  editorType: "RectangleEditor",
  type: 51,
  value: "#ff0000",
  propertyName: "stroke",
  ...
}
```

### 步骤 4: 分析问题

#### 情况 A: 没有看到 "派发参数事件"

**原因**: 事件监听器没有绑定
**解决**: DOM 元素为 undefined，检查元素获取

#### 情况 B: 看到 "派发参数事件"，但没有 "UIManager.updateParams"

**原因**: EventBus 没有正确传递事件
**解决**: 检查 EventBus 监听器绑定

#### 情况 C: 看到 "UIManager.updateParams"，但 propertyName 为 undefined

**原因**: typesMap 没有正确映射参数类型
**解决**: 检查 RectangleEditor.typesMap

#### 情况 D: 所有日志都正常，但矩形仍是黑色

**原因**:

1. 参数更新在绘制之后（需要先调整参数，再绘制）
2. 或者绘制时没有使用 \_defaultDrawingOptions

## 预期的正确流程

```
用户操作: 调整颜色 → #ff0000
  ↓
[annotation_editor_params.js] 派发参数事件: RECTANGLE_COLOR #ff0000
  ↓
[tools.js] UIManager.updateParams 接收事件
  ↓
[draw.js] RectangleEditor.updateDefaultParams
  ↓
更新 _defaultDrawingOptions.stroke = "#ff0000"
  ↓
用户操作: 绘制矩形
  ↓
使用 _defaultDrawingOptions 创建矩形
  ↓
结果: 红色矩形
```

## 常见问题

### Q1: 为什么已经绘制的矩形不会改变颜色？

A: 这是正常行为。参数调整只影响：

- **未选中时**: 新绘制的矩形
- **选中时**: 当前选中的矩形

### Q2: 如何修改已经绘制的矩形？

A:

1. 点击选中该矩形
2. 然后调整参数
3. 矩形会实时更新

### Q3: 为什么有两个重叠的编辑器 div？

A: 这是异常情况，可能原因：

- 绘制事件触发了两次
- 编辑器创建逻辑有 bug
- 需要进一步调试

## 问题解决

### 根本原因

DOM 元素获取为 `undefined` 的原因是：**`npx gulp server` 使用的是构建后的文件，而不是源文件**。

当您修改 `web/viewer.html` 后，需要重新构建才能生效：

```bash
npx gulp generic
```

### 解决步骤

1. **停止当前的 gulp server**（Ctrl+C）

2. **重新构建项目**：

   ```bash
   npx gulp generic
   ```

3. **重新启动 server**：

   ```bash
   npx gulp server
   ```

4. **刷新浏览器**并重新测试

### 验证修复

刷新后，控制台应该显示：

```
[DEBUG] 几何工具参数元素状态: {
  editorGeoShapeColor: <input type="color">,
  editorGeoShapeThickness: <input type="range">,
  editorGeoShapeOpacity: <input type="range">
}
```

如果仍然是 `undefined`，说明还有其他问题。
