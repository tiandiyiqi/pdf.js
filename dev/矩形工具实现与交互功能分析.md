# 矩形工具实现与交互功能分析

## 0. 矩形工具当前实现总结

### 0.1 核心架构

矩形工具通过以下类实现：

```
AnnotationEditor (基类)
    ↓ 继承
DrawingEditor (绘图基类)
    ↓ 继承
RectangleEditor (矩形编辑器)
```

### 0.2 关键组件

1. **RectangleEditor** (`src/display/editor/rectangle.js`)
   - 继承自 `DrawingEditor`
   - 编辑器类型：`AnnotationEditorType.GEOSHAPE`
   - 主要特性：
     - 单次绘制模式 (`supportMultipleDrawings: false`)
     - 不保持宽高比 (`_willKeepAspectRatio: false`)
     - 参数类型映射：`RECTANGLE_THICKNESS` → `stroke-width`, `RECTANGLE_COLOR` → `stroke`, `RECTANGLE_OPACITY` → `stroke-opacity`

2. **RectDrawingOptions** (`src/display/editor/rectangle.js`)
   - 管理矩形的SVG绘图属性
   - 默认属性：
     - `fill: "none"` (无填充)
     - `stroke: AnnotationEditor._defaultLineColor` (边框颜色)
     - `stroke-width: 1` (边框粗细)
     - `stroke-linecap: "square"` (方形端点)
     - `stroke-linejoin: "miter"` (斜接连接)

3. **RectDrawOutliner/RectDrawOutline** (`src/display/editor/drawers/rectangledraw.js`)
   - `RectDrawOutliner`: 处理矩形绘制过程中的实时更新
   - `RectDrawOutline`: 表示完成的矩形轮廓数据

### 0.3 参数管理流程

```
UI控件 (viewer.html)
   ↓ 用户输入
AnnotationEditorParams (annotation_editor_params.js)
   ↓ 派发事件 (annotationeditorparamschanged)
AnnotationEditorUIManager (tools.js)
   ↓ updateParams()
RectangleEditor.updateParams()
   ↓ 更新 _drawingOptions
DrawLayer.updateProperties()
   ↓ 更新SVG
最终渲染
```

### 0.4 绘制流程

1. **初始化**: 用户点击矩形按钮，工具模式切换为 `GEOSHAPE`
2. **开始绘制**: `DrawingEditor.startDrawing()` → 创建 `RectDrawOutliner` 实例
3. **拖动绘制**: `_drawMove()` → `RectDrawOutliner.update()` → 更新SVG路径
4. **结束绘制**: `_endDraw()` → `endDrawing()` → 创建 `RectangleEditor` 实例
5. **序列化**: `RectangleEditor.serialize()` → 生成PDF批注数据

### 0.5 当前存在的问题

1. **缺少颜色选择器按钮**: `toolbarButtons` getter 返回空数组 `[]`
2. **参数应用机制**: 虽然已实现参数类型映射，但默认参数的应用需要通过几何工具面板预设

## 1. 绘图工具（InkEditor）交互功能实现分析

### 1.1 鼠标悬停显示方框

**实现位置**: `AnnotationEditor` 基类

**关键方法**: `select()` (editor.js: 2130-2151行)

```javascript
select() {
  if (this.isSelected && this._editToolbar) {
    this._editToolbar.show();
    return;
  }
  this.isSelected = true;
  this.makeResizable();  // 创建调整大小的手柄
  this.div?.classList.add("selectedEditor");  // 添加CSS类，显示蓝色边框
  if (!this._editToolbar) {
    this.addEditToolbar().then(() => {
      if (this.div?.classList.contains("selectedEditor")) {
        this._editToolbar?.show();
      }
    });
    return;
  }
  this._editToolbar?.show();
  this.#altText?.toggleAltTextBadge(false);
}
```

**CSS机制**:

- 编辑器的 `div` 元素有一个默认的边框样式
- 当鼠标悬停时，浏览器的 `:hover` 伪类会触发CSS样式变化
- 边框的可见性通过CSS的 `outline` 或 `border` 属性控制

### 1.2 点击后方框变为蓝色

**实现位置**: `AnnotationEditor.select()` 方法

**机制**:

1. 用户点击编辑器时，`pointerdown` 事件触发 `pointerdown()` 方法 (editor.js: 1434-1449行)
2. `pointerdown()` 调用 `parent.setSelected(this)`
3. `setSelected()` 最终调用 `select()` 方法
4. `select()` 添加 `"selectedEditor"` CSS类到编辑器的 `div`

```javascript
pointerdown(event) {
  const { isMac } = FeatureTest.platform;
  if (event.button !== 0 || (event.ctrlKey && isMac)) {
    event.preventDefault();
    return;
  }
  this.#hasBeenClicked = true;

  if (this._isDraggable) {
    this.#setUpDragSession(event);
    return;
  }

  this.#selectOnPointerEvent(event);  // 触发选择
}
```

**CSS样式**:

```css
/* 假设的CSS规则 */
.annotationEditorLayer .selectedEditor {
  outline: 2px solid #0060df; /* 蓝色边框 */
  outline-offset: 1px;
}
```

### 1.3 调整大小的手柄（Resizers）

**实现位置**: `AnnotationEditor.makeResizable()` (editor.js: 1937-1942行)

```javascript
makeResizable() {
  if (this.isResizable) {
    this.#createResizers();  // 创建调整大小的手柄
    this.#resizersDiv.classList.remove("hidden");
  }
}
```

**手柄创建**: `#createResizers()` (editor.js: 763-799行)

- 创建一个 `div.resizers` 容器
- 根据 `_willKeepAspectRatio` 决定手柄数量：
  - `true`: 4个角的手柄（topLeft, topRight, bottomRight, bottomLeft）
  - `false`: 8个手柄（4个角 + 4个边中点）
- 每个手柄都是一个 `div.resizer` 元素，带有相应的类名（如 `topLeft`, `bottomRight`）
- 绑定 `pointerdown` 事件用于调整大小

### 1.4 右下角3个图标（颜色、批注、删除）

**实现位置**: `AnnotationEditor.addEditToolbar()` (editor.js: 1068-1086行)

```javascript
async addEditToolbar() {
  if (this._editToolbar || this.#isInEditMode) {
    return this._editToolbar;
  }
  this._editToolbar = new EditorToolbar(this);
  this.div.append(this._editToolbar.render());

  const { toolbarButtons } = this;  // 获取子类定义的按钮
  if (toolbarButtons) {
    for (const [name, tool] of toolbarButtons) {
      await this._editToolbar.addButton(name, tool);
    }
  }

  if (!this.hasComment) {
    this._editToolbar.addButton("comment", this.addCommentButton());
  }
  this._editToolbar.addButton("delete");  // 删除按钮

  return this._editToolbar;
}
```

**InkEditor的按钮定义**: (`ink.js`: 193-196行)

```javascript
get toolbarButtons() {
  this._colorPicker ||= new BasicColorPicker(this);
  return [["colorPicker", this._colorPicker]];  // 返回颜色选择器按钮
}
```

**EditorToolbar实现**: (`toolbar.js`)

1. **创建工具栏DOM** (`render()` 方法，49-80行):

```javascript
render() {
  const editToolbar = (this.#toolbar = document.createElement("div"));
  editToolbar.classList.add("editToolbar", "hidden");
  editToolbar.setAttribute("role", "toolbar");

  const buttons = (this.#buttons = document.createElement("div"));
  buttons.className = "buttons";
  editToolbar.append(buttons);

  const position = this.#editor.toolbarPosition;
  if (position) {
    const { style } = editToolbar;
    const x = this.#editor._uiManager.direction === "ltr"
      ? 1 - position[0]
      : position[0];
    style.insetInlineEnd = `${100 * x}%`;
    style.top = `calc(${100 * position[1]}% + var(--editor-toolbar-vert-offset))`;
  }

  return editToolbar;
}
```

2. **添加按钮** (`addButton()` 方法，211-237行):

```javascript
async addButton(name, tool) {
  switch (name) {
    case "colorPicker":
      if (tool) {
        this.addColorPicker(tool);
      }
      break;
    case "comment":
      if (tool) {
        this.addComment(tool);
      }
      break;
    case "delete":
      this.addDeleteButton();
      break;
    // ... 其他按钮类型
  }
}
```

3. **工具栏定位**:
   - 通过 `toolbarPosition` getter获取相对位置（默认 `[1, 0]` 表示右下角）
   - 使用CSS的 `insetInlineEnd` 和 `top` 属性定位
   - `insetInlineEnd` 支持LTR/RTL布局

## 2. 如何让矩形工具具有相同功能

### 2.1 当前矩形工具的缺失部分

**分析 RectangleEditor 当前实现** (`rectangle.js`: 205-207行):

```javascript
get toolbarButtons() {
  return [];  // 空数组，不返回任何自定义按钮
}
```

**对比 InkEditor** (`ink.js`: 193-196行):

```javascript
get toolbarButtons() {
  this._colorPicker ||= new BasicColorPicker(this);
  return [["colorPicker", this._colorPicker]];  // 返回颜色选择器
}
```

### 2.2 矩形工具已经具备的功能

根据继承关系，`RectangleEditor` 从 `AnnotationEditor` 基类继承了以下功能：

✅ **已具备**:

1. **选中时的蓝色边框**: 通过 `select()` 方法添加 `selectedEditor` 类
2. **调整大小的手柄**: 通过 `makeResizable()` 和 `isResizable` getter (DrawingEditor返回true)
3. **批注按钮**: 在 `addEditToolbar()` 中自动添加
4. **删除按钮**: 在 `addEditToolbar()` 中自动添加
5. **工具栏定位**: 继承自基类的默认行为

❌ **缺失**:

1. **颜色选择器按钮**: `toolbarButtons` 返回空数组

### 2.3 为什么矩形工具也需要颜色选择器按钮

结合你最新的需求（“矩形的颜色选择器也需要”），矩形工具应该和绘图工具一致：**选中矩形后在右下角工具栏提供颜色按钮，用于修改已绘制矩形的颜色**。

**设计原则**:

- **绘图工具（InkEditor）**: 绘制后可修改颜色 → 工具栏需要颜色选择器
- **几何工具（RectangleEditor）**: 既要支持绘制前预设（几何面板），也要支持绘制后微调（工具栏颜色选择器）

**实现机制（两条链路并存）**:

1. **绘制前预设（默认值）**：
   - 几何工具面板参数（`editorGeoShapeColor`, `editorGeoShapeThickness`, `editorGeoShapeOpacity`）
   - `AnnotationEditorParams` → `AnnotationEditorUIManager.updateParams` → `RectangleEditor.updateDefaultParams`
   - 更新 `RectangleEditor._defaultDrawingOptions`，影响“下一次新画”的矩形
2. **绘制后修改（当前对象）**：
   - 选中矩形 → `AnnotationEditor.addEditToolbar()` 创建 `EditorToolbar`
   - `RectangleEditor.toolbarButtons` 返回 `colorPicker` → `BasicColorPicker` 修改当前 editor 的 `RECTANGLE_COLOR`
   - 走 `RectangleEditor.updateParams()` → `DrawingEditor._updateProperty()` → `drawLayer.updateProperties()` 即时更新

### 2.5 如何为矩形工具添加颜色选择器（推荐实现）

按 InkEditor 的方式实现即可：让 `RectangleEditor.toolbarButtons` 返回 `colorPicker`。

**修改 `RectangleEditor.toolbarButtons`** (`rectangle.js`):

```javascript
// 当前实现
get toolbarButtons() {
  return [];
}

// 修改为（推荐）
get toolbarButtons() {
  this._colorPicker ||= new BasicColorPicker(this);
  return [["colorPicker", this._colorPicker]];
}
```

**注意事项（很重要）**:

- 这会形成两个入口：
  - 几何工具面板：影响“下一次绘制”的默认颜色
  - 工具栏颜色按钮：影响“当前选中的矩形”的颜色
- 为避免用户困惑，建议在**选中矩形时**同步更新几何工具面板的颜色显示（由 `propertiesToUpdate` / `annotationeditorparamschanged` 链路驱动），让面板反映当前选中矩形的颜色。

### 2.6 推荐的最终实现

**启用工具栏颜色选择器**（`toolbarButtons` 提供 `colorPicker`）:

**理由**:

1. ✅ **满足“绘制后编辑”**：选中后可直接改色，符合你要求
2. ✅ **与 InkEditor 的交互一致**：同样在右下角工具栏提供颜色入口
3. ✅ **保留“绘制前预设”**：几何面板依然用于默认值（下一次绘制）

**工具栏应该包含的按钮**:

- ✅ 颜色按钮（修改当前选中矩形的颜色）
- ✅ 批注按钮（添加评论）
- ✅ 删除按钮（删除矩形）

## 3. 技术细节补充

### 3.1 CSS类名总结

| CSS类名           | 作用         | 添加时机                     |
| ----------------- | ------------ | ---------------------------- |
| `.selectedEditor` | 蓝色选中边框 | `select()` 方法              |
| `.resizers`       | 调整手柄容器 | `#createResizers()` 方法     |
| `.resizer`        | 单个调整手柄 | `#createResizers()` 循环添加 |
| `.editToolbar`    | 工具栏容器   | `EditorToolbar.render()`     |
| `.draggable`      | 可拖动状态   | 设置 `_isDraggable` 属性时   |
| `.disabled`       | 禁用编辑状态 | `disableEditing()` 方法      |

### 3.2 事件流总结

```
用户点击编辑器
    ↓
pointerdown 事件 (bindEvents绑定)
    ↓
AnnotationEditor.pointerdown()
    ↓
#selectOnPointerEvent() 或 #setUpDragSession()
    ↓
parent.setSelected(this) 或 parent.toggleSelected(this)
    ↓
AnnotationEditor.select()
    ↓
并行执行：
  - makeResizable() → 创建调整手柄
  - div.classList.add("selectedEditor") → 蓝色边框
  - addEditToolbar() → 创建工具栏
        ↓
    EditorToolbar.render() → 创建DOM
        ↓
    循环 toolbarButtons → 添加自定义按钮
        ↓
    addButton("comment") → 添加批注按钮
        ↓
    addButton("delete") → 添加删除按钮
```

### 3.3 工具栏按钮类型

| 按钮类型        | 参数                    | 实现方法                   | 用途         |
| --------------- | ----------------------- | -------------------------- | ------------ |
| `colorPicker`   | `BasicColorPicker` 实例 | `addColorPicker()`         | 调整颜色     |
| `altText`       | `AltText` 实例          | `addAltText()`             | 添加替代文本 |
| `comment`       | `Comment` 实例          | `addComment()`             | 添加评论     |
| `delete`        | 无                      | `addDeleteButton()`        | 删除编辑器   |

## 5. 结论

### 5.1 矩形工具的交互功能状态

**已完全实现的功能**:

1. ✅ 鼠标悬停显示方框（继承自基类CSS）
2. ✅ 点击后方框变为蓝色（`select()` 方法 + `selectedEditor` 类）
3. ✅ 调整大小的手柄（`makeResizable()` + 8个手柄）
4. ✅ 右下角工具栏（`addEditToolbar()`）
5. ✅ 颜色按钮（通过 `toolbarButtons` 添加 `colorPicker`）
6. ✅ 批注按钮（自动添加）
7. ✅ 删除按钮（自动添加）

### 5.2 与绘图工具的差异

| 特性           | InkEditor | RectangleEditor | 原因           |
| -------------- | --------- | --------------- | -------------- |
| 工具栏颜色按钮 | ✅        | ✅              | 交互一致       |
| 调整手柄数量   | 4个角     | 8个（4角+4边）  | 宽高比约束不同 |
| 多次绘制       | ✅        | ❌              | 绘图模式不同   |
| 参数设置时机   | 绘制后    | 绘制前          | 工作流程不同   |

### 5.3 开发建议

1. **启用颜色按钮**: 在 `RectangleEditor.toolbarButtons` 中返回 `colorPicker`
2. **面板同步**: 选中矩形时，让几何面板显示当前矩形的颜色/粗细/透明度（避免两个入口造成认知分裂）
3. **参数应用验证**: 确保几何面板默认值仍能正确应用到“下一次新画”的矩形
4. **CSS一致性**: 确保矩形编辑器的选中样式、手柄样式与其他 editor 一致
5. **文档说明**: 明确“面板影响默认值、工具栏影响当前选中对象”的规则
