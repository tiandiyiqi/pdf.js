# 图像过滤完整修复方案

## 🔍 问题分析

用户反馈：

1. **大图像降采样**后，色彩过滤没有达到理想效果
2. **链接图像**（使用内嵌缩略图）的色彩过滤不正常

## 📊 调用链分析

### 正常路径（工作正常）

```
image.js:924 → colorSpace.fillRgb(..., colorFilterConfig)
  ↓
getRgbBuffer(..., colorFilterConfig)  // 应用颜色过滤
  ↓
降采样（如果需要）
  ↓
返回过滤后的图像
```

**此路径正常工作**：颜色过滤在降采样之前进行。

### 问题路径（缺少颜色过滤）

#### 路径1：DeviceCMYK的快速路径

```javascript
// 文件：src/core/image.js
// 行号：858-869

case "DeviceCMYK":
  imgData.kind = ImageKind.RGB_24BPP;
  imgData.data = await this.getImageBytes(imageLength, {
    drawWidth,
    drawHeight,
    forceRGB: true,  // ← 在JPEG解码器中直接转换为RGB
  });
  if (mustBeResized) {
    return ImageResizer.createImage(imgData);  // ← 直接降采样，没有经过fillRgb！
  }
  return imgData;
```

**问题**：

- `getImageBytes(..., { forceRGB: true })` 调用JPEG解码器直接将CMYK转换为RGB
- **没有经过 `colorSpace.fillRgb()`，因此没有应用颜色过滤**
- 然后直接降采样并返回

#### 路径2：DeviceRGBA的快速路径

```javascript
// 文件：src/core/image.js
// 行号：727-747

if (!this.smask && !this.mask && this.colorSpace.name === "DeviceRGBA") {
  imgData.kind = ImageKind.RGBA_32BPP;
  const imgArray = (imgData.data = await this.getImageBytes(
    originalHeight * originalWidth * 4,
    {}
  ));

  if (isOffscreenCanvasSupported) {
    if (!mustBeResized) {
      return this.createBitmap(...);
    }
    return ImageResizer.createImage(imgData);  // ← 直接降采样
  }

  return imgData;
}
```

**问题**：

- 虽然这是RGBA颜色空间，理论上不需要颜色过滤
- 但如果原始数据实际是CMYK（通过JPEG解码器转换），则缺少过滤

## 🔧 修复策略

### 策略A：在特殊路径中添加颜色过滤

**优点**：

- 精确控制，不破坏现有流程
- 只修改有问题的路径

**缺点**：

- 需要在多个地方添加代码
- 维护复杂度增加

### 策略B：强制所有CMYK图像走fillRgb路径（推荐）

**优点**：

- 统一处理流程
- 保证所有CMYK图像都经过颜色过滤
- 代码更清晰

**缺点**：

- 可能稍微降低某些情况下的性能（但用户已经反馈性能很好）

## ✅ 推荐方案：策略B

### 修改位置

**文件**：`src/core/image.js`  
**方法**：`createImageData()`

**修改思路**：

1. 移除或注释掉 `DeviceCMYK` 的快速路径（第858-869行）
2. 让所有CMYK图像都走正常的 `fillRgb()` 路径

### 具体修改

#### 修改1：注释掉DeviceCMYK快速路径

```javascript
// 修改前（858-869行）
case "DeviceCMYK":
  imgData.kind = ImageKind.RGB_24BPP;
  imgData.data = await this.getImageBytes(imageLength, {
    drawWidth,
    drawHeight,
    forceRGB: true,
  });
  if (mustBeResized) {
    return ImageResizer.createImage(imgData);
  }
  return imgData;

// 修改后：注释掉或删除，让CMYK图像走正常流程
// 正常流程会经过fillRgb()进行颜色过滤
```
