# 矩形工具参数问题排查总结

## 问题描述

用户设置了颜色（红色）、粗细、透明度，但绘制的矩形仍然是黑色，参数没有生效。

## 问题根源

**DOM 元素获取失败**：`editorGeoShapeColor`、`editorGeoShapeThickness`、`editorGeoShapeOpacity` 都是 `undefined`。

### 原因分析

1. **构建系统问题**：`npx gulp server` 使用的是 `build/generic/web/` 目录中的构建后文件
2. **文件未同步**：修改 `web/viewer.html` 后，如果不重新构建，构建目录中的文件不会更新
3. **事件监听器未绑定**：因为 DOM 元素为 `undefined`，所以事件监听器没有成功绑定
4. **参数无法更新**：用户调整参数时，没有任何事件被触发

## 解决方案

### 立即修复

```bash
# 1. 停止当前的 gulp server (Ctrl+C)

# 2. 重新构建项目
npx gulp generic

# 3. 重新启动 server
npx gulp server

# 4. 刷新浏览器
```

### 验证修复

刷新浏览器后，打开控制台，应该看到：

```
[DEBUG] 几何工具参数元素状态: {
  editorGeoShapeColor: <input type="color" id="editorGeoShapeColor">,
  editorGeoShapeThickness: <input type="range" id="editorGeoShapeThickness">,
  editorGeoShapeOpacity: <input type="range" id="editorGeoShapeOpacity">
}
```

然后测试：

1. 点击几何工具按钮
2. 调整颜色为红色
3. 应该看到：`[DEBUG] 派发参数事件: RECTANGLE_COLOR #ff0000 类型: 51`
4. 绘制矩形
5. 矩形应该是红色的

```
用户操作: 调整颜色 → #ff0000
  ↓
[annotation_editor_params.js]
  - editorGeoShapeColor.addEventListener("input") 触发
  - 派发参数事件: RECTANGLE_COLOR #ff0000
  ↓
[EventBus]
  - 传递 "switchannotationeditorparams" 事件
  ↓
[tools.js] AnnotationEditorUIManager.updateParams
  - 接收事件: type=51, value="#ff0000"
  - 检查是否有选中的编辑器
  - 如果没有选中，调用所有编辑器类型的 updateDefaultParams
  ↓
[draw.js] RectangleEditor.updateDefaultParams
  - 使用 typesMap 映射: 51 → "stroke"
  - 更新 _defaultDrawingOptions.stroke = "#ff0000"
  ↓
用户操作: 绘制矩形
  ↓
[draw.js] DrawingEditor.startDrawing
  - 调用 getDefaultDrawingOptions()
  - 使用 _defaultDrawingOptions 创建矩形
  ↓
[draw_layer.js] DrawLayer.draw
  - 创建 SVG <rect> 元素
  - 应用属性: stroke="#ff0000"
  ↓
结果: 红色矩形显示在页面上
```

## 开发注意事项

### 修改前端文件后的工作流

1. **修改源文件**：编辑 `web/` 目录下的文件
2. **重新构建**：运行 `npx gulp generic`
3. **重启服务器**：重新运行 `npx gulp server`
4. **刷新浏览器**：硬刷新（Ctrl+Shift+R 或 Cmd+Shift+R）

### 常见陷阱

❌ **错误做法**：

- 只修改源文件，不重新构建
- 修改 `build/` 目录下的文件（会被覆盖）

✅ **正确做法**：

- 始终修改 `web/`、`src/` 等源文件
- 修改后立即重新构建
- 使用 `npx gulp watch` 自动监听文件变化（如果支持）

- `pdfjs_internal_editor_0` - 有 `selectedEditor` 类
- `pdfjs_internal_editor_1` - 没有 `selectedEditor` 类

**状态**：待进一步调查
**可能原因**：

- 编辑器创建逻辑有 bug
- 之前的编辑器没有正确清理
