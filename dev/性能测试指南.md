## 🧪 详细测试方案

### 测试1：功能验证

**目的**：确保颜色过滤功能正常

**步骤**：

1. 加载包含CMYK图像的PDF
2. 打开油墨清单（Ink List）
3. 点击眼睛图标，隐藏/显示各个颜色通道
4. 验证图像颜色正确变化

**预期**：

- ✅ 隐藏Cyan时，青色通道消失
- ✅ 隐藏Magenta时，洋红色通道消失
- ✅ 隐藏Yellow时，黄色通道消失
- ✅ 隐藏Black时，黑色通道消失
- ✅ 专色过滤正常工作

### 测试2：性能对比

**目的**：测量实际性能提升

**步骤**：

1. 打开开发者工具 Performance 面板
2. 点击 Record 开始记录
3. 加载包含大图像的PDF页面
4. 停止记录
5. 分析性能数据

**关注指标**：

- **Total Time**：总耗时
- **Scripting**：JavaScript执行时间
- **Rendering**：渲染时间
- **Painting**：绘制时间

**预期**：

- Scripting时间显著减少（90%+）
- 无fetch请求（Network面板应该很少活动）
- 无大量console.log

### 测试3：内存使用

**目的**：验证内存优化效果

**步骤**：

1. 打开开发者工具 Memory 面板
2. 拍摄堆快照（Heap Snapshot）
3. 加载大图像PDF
4. 再次拍摄堆快照
5. 对比内存使用

**预期**：

- ✅ 内存使用合理（无明显泄漏）
- ✅ TypedArray使用正确
- ✅ 无大量临时数组堆积

### 测试4：多图像测试

**目的**：测试包含多个图像的PDF

**步骤**：

1. 加载包含多个CMYK图像的PDF
2. 快速翻页
3. 观察响应速度

**预期**：

- ✅ 第一次加载稍慢（正常）
- ✅ 第二次加载很快（缓存生效）
- ✅ 翻页流畅无卡顿

## 🔍 问题排查

### 如果性能仍然很慢

1. **检查console.log**
   - 打开Console面板
   - 看是否有大量日志输出
   - 如果有，说明调试代码未完全移除

2. **检查Network面板**
   - 打开Network面板
   - 看是否有fetch请求到7242端口
   - 如果有，说明调试代码未完全移除

3. **检查Performance面板**
   - 记录性能数据
   - 看是否有长时间的Scripting任务
   - 分析瓶颈所在

### 如果颜色过滤不工作

1. **检查ColorFilterConfig**
   - 在Console输入：`ColorConverter.getColorFilterConfig()`
   - 验证配置是否正确

2. **检查油墨清单**
   - 确认油墨清单显示正确
   - 确认点击眼睛图标后状态改变

3. **检查Worker同步**
   - 确认配置正确同步到Worker线程
   - 查看Worker中的ColorConverter配置

## 📈 性能基准测试

### 推荐测试图像

创建或使用以下测试图像：

1. **小图像（100x100）**
   - 用于验证基本功能
   - 预期：100ms内完成

2. **中等图像（500x500）**
   - 用于验证日常使用性能
   - 预期：0.5-1秒内完成

3. **大图像（1000x1000）**
   - 用于验证优化效果
   - 预期：2-5秒内完成

4. **超大图像（2000x2000+）**
   - 用于压力测试
   - 预期：10-20秒内完成

### 测试脚本

在Console中运行：

```javascript
// 测试图像加载性能
async function testImagePerformance() {
  const startTime = performance.now();

  // 这里假设你已经加载了PDF
  // 等待页面渲染完成
  await new Promise(resolve => {
    PDFViewerApplication.eventBus.on("pagerendered", resolve, { once: true });
  });

  const endTime = performance.now();
  console.log(`图像加载耗时: ${(endTime - startTime).toFixed(2)}ms`);

  return endTime - startTime;
}

// 运行测试
testImagePerformance().then(time => {
  console.log(`测试完成！总耗时: ${time.toFixed(2)}ms`);
});
```

## 🎓 学习要点

### 性能优化的关键经验

1. **移除调试代码**
   - 调试代码是性能杀手
   - 生产环境必须移除
   - 可以用环境变量控制

2. **批量处理**
   - 避免逐元素处理
   - 直接操作TypedArray
   - 让编译器优化循环

3. **减少对象创建**
   - 临时数组创建成本高
   - 优先复用现有数组
   - 使用TypedArray提高性能

4. **性能监控**
   - 使用performance.now()
   - 使用Performance面板
   - 量化优化效果
