# 矩形交互功能修复说明

## 问题描述

用户报告矩形创建后出现以下问题：

1. ❌ 颜色选择器显示在页面左侧，而不是矩形右下角
2. ❌ 缺少批注和删除按钮
3. ❌ 工具栏未正确创建

## 根本原因

### 问题 1: `BasicColorPicker` 缺少 `rectangle` 类型支持

**文件**: `src/display/editor/color_picker.js`

**问题代码** (第327-330行):

```javascript
BasicColorPicker.#l10nColor ||= Object.freeze({
  freetext: "pdfjs-editor-color-picker-free-text-input",
  ink: "pdfjs-editor-color-picker-ink-input",
  // 缺少 rectangle 类型！
});
```

**问题分析**:

- `BasicColorPicker.renderButton()` 在第337行获取 `editorType`
- 在第343行尝试设置 `data-l10n-id` 属性：
  ```javascript
  input.setAttribute("data-l10n-id", BasicColorPicker.#l10nColor[editorType]);
  ```
- 当 `editorType` 为 `"rectangle"` 时，`BasicColorPicker.#l10nColor["rectangle"]` 返回 `undefined`
- 这导致颜色选择器初始化失败或行为异常

### 问题 2: 本地化字符串缺失

**文件**: `l10n/en-US/viewer.ftl` 和 `l10n/zh-CN/viewer.ftl`

即使添加了 `rectangle` 类型到 `#l10nColor`，也需要对应的本地化字符串：

- `pdfjs-editor-color-picker-rectangle-input`

## 解决方案

### 修改 1: 添加 `rectangle` 类型支持

**文件**: `src/display/editor/color_picker.js` (第327-331行)

```javascript
BasicColorPicker.#l10nColor ||= Object.freeze({
  freetext: "pdfjs-editor-color-picker-free-text-input",
  ink: "pdfjs-editor-color-picker-ink-input",
  rectangle: "pdfjs-editor-color-picker-rectangle-input", // ✅ 新增
});
```

### 修改 2: 添加英文本地化

**文件**: `l10n/en-US/viewer.ftl`

```ftl
pdfjs-editor-color-picker-ink-input =
    .title = Change drawing color
pdfjs-editor-ink-button-label = Draw
pdfjs-editor-color-picker-rectangle-input =
    .title = Change rectangle color
```

### 修改 3: 添加中文本地化

**文件**: `l10n/zh-CN/viewer.ftl`

```ftl
pdfjs-editor-color-picker-ink-input =
    .title = 更改绘图颜色
pdfjs-editor-ink-button-label = 绘图
pdfjs-editor-color-picker-rectangle-input =
    .title = 更改矩形颜色
```

## 技术细节

### `BasicColorPicker` 工作流程

1. **创建** (`constructor`):
   - 接收 `editor` 参数
   - 初始化 `#l10nColor` 映射表

2. **渲染按钮** (`renderButton`):

   ```javascript
   const { editorType, colorType, color } = this.#editor;
   const input = document.createElement("input");
   input.type = "color";
   input.value = color || "#000000";
   input.className = "basicColorPicker";
   input.setAttribute("data-l10n-id", BasicColorPicker.#l10nColor[editorType]);
   ```

3. **添加到工具栏** (`EditorToolbar.addColorPicker`):
   ```javascript
   const button = colorPicker.renderButton();
   this.#buttons.append(button, this.#divider);
   ```

### `editorType` 的值

不同编辑器的 `editorType` 值：

- `FreeTextEditor`: `"freetext"`
- `InkEditor`: `"ink"`
- `RectangleEditor`: `"rectangle"` ← 之前未支持

### 为什么需要 l10n 键

`data-l10n-id` 属性用于：

1. **无障碍支持**: 屏幕阅读器读取本地化的提示文本
2. **国际化**: 根据用户语言显示正确的提示
3. **工具提示**: 鼠标悬停时显示 `title` 属性

如果 `data-l10n-id` 为 `undefined`：

- 可能导致本地化系统报错
- 工具提示不显示或显示错误
- 影响用户体验
