# ⚡ 链接图像修复验证 - 快速指南

## 🎯 发现的问题

之前的修复**不完整**！虽然禁用了ImageDecoder，但**forceRGBA仍然跳过颜色过滤**！

## ✅ 已修复的问题

**第二层快速路径**：`getImageBytes(..., { forceRGBA: true })`

这个调用让JPEG解码器直接转换CMYK→RGBA，完全跳过了PDF.js的颜色过滤系统！

## 🔧 修复内容

**文件**：`src/core/image.js`  
**位置**：第830-841行

**修改**：当启用颜色过滤时，DeviceCMYK不设置 `isHandled = true`，从而跳过快速路径。

2. 勾选"缓存"
3. 清除

### 3. 检查代码

确认 `src/core/image.js` 第830-841行是否包含修复：
