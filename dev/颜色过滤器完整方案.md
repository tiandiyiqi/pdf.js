# 颜色过滤器完整实现方案

## 方案概述

本方案通过在ColorConverter中集成颜色过滤功能，实现对CMYK通道和专色的动态控制。方案保持向后兼容，不影响现有功能。同时实现了完整的UI界面，支持按页面管理油墨状态，并提供批量操作功能。

## 核心实现

### 1. ColorConverter颜色过滤器

在 `src/core/color_converter.js` 中实现颜色过滤逻辑：

**核心功能：**

- 静态颜色过滤器配置管理
- CMYK通道过滤
- 专色过滤
- 动态状态更新

**关键方法：**

- `setColorFilterConfig(config)` - 设置过滤器配置
- `getColorFilterConfig()` - 获取当前配置
- `updateColorState(colorName, visible)` - 更新单个颜色状态
- `addSpotColor(spotName, visible)` - 添加专色
- `cmykToRgbWithFilter(cmyk)` - 带过滤的CMYK转RGB
- `deviceNToRgbWithFilter(channels)` - 带过滤的DeviceN转RGB

### 2. PDFInkListViewer油墨清单UI

在 `web/pdf_ink_list_viewer.js` 中实现完整的油墨清单界面。

#### 2.1 状态管理架构

**按页面存储状态：**

```javascript
// 持久化的油墨可见性状态（按页面存储）
this.inkVisibilityState = new Map(); // Map<pageNumber, Map<inkName, visible>>
```

**状态管理方法：**

- `_getPageVisibilityState(pageNumber)` - 获取指定页面的状态Map
- `_getInkVisibility(pageNumber, inkName, defaultValue)` - 获取指定油墨在指定页面的可见性
- `_setInkVisibility(pageNumber, inkName, visible)` - 设置指定油墨在指定页面的可见性

**特点：**

- ✅ 每个页面的油墨状态独立存储
- ✅ 切换页面时自动恢复对应页面的状态
- ✅ 文档重新加载后状态不丢失
- ✅ CMYK组和所有通道都按页面独立管理

#### 2.2 页面事件监听

**监听的事件：**

- `pagerendered` - 页面渲染完成时，提取页面颜色信息
- `pagechanging` - 页面切换时，更新当前页面号并恢复状态
- `pagesloaded` - 文档加载完成时，初始化第一页

**工作流程：**

1. 页面渲染完成 → 提取颜色信息 → 保存到 `pageColorStates`
2. 页面切换 → 更新 `currentPageNumber` → 从对应页面状态恢复油墨清单
3. 文档重新加载 → 保留 `inkVisibilityState` → 恢复各页面状态

#### 2.3 UI组件

**控制按钮行：**

- 位置：油墨清单最上方
- 按钮：
  - "全部显示" - 将当前页面的所有油墨设置为可见
  - "全部隐藏" - 将当前页面的所有油墨设置为隐藏
- 特点：
  - 只作用于当前页面（不影响其他页面）
  - 两个按钮平均分配水平空间
  - 行高与其他行一致

**油墨项：**

- CMYK组 - 点击可同时控制四个通道
- CMYK通道（青色、洋红色、黄色、黑色）
- 专色 - 动态检测并显示

**眼睛图标：**

- `eyeVisible` - 可见状态（眼睛打开图标）
- `eyeHidden` - 隐藏状态（灰色眼睛图标，opacity: 0.6）

#### 2.4 状态同步机制

**点击眼睛图标时：**

1. 更新 `ink.visible` 状态
2. 保存到当前页面的持久化存储：`_setInkVisibility(currentPageNumber, inkName, visible)`
3. 更新眼睛图标样式
4. 更新 ColorConverter 状态
5. 更新CMYK组图标状态（如果是通道）
6. 触发 `inkstatechanged` 事件

**文档重新加载时：**

1. `app.js` 监听 `inkstatechanged` 事件
2. 保存当前视图状态（页码、缩放、滚动位置）
3. 重新加载文档：`this.open({ url: this.url })`
4. 同步配置到Worker线程：`pdfDocument.updateColorFilterConfig(config)`
5. 清除缓存并重新渲染
6. 恢复视图状态
7. 从持久化存储恢复油墨清单状态

### 3. 文档重新加载流程（方案A）

在 `web/app.js` 中实现文档重新加载机制：

**流程：**

1. 用户点击眼睛图标
2. 主线程更新ColorConverter配置
3. 触发 `inkstatechanged` 事件
4. 保存当前视图状态
5. 重新打开文档
6. 同步配置到Worker线程
7. 清除operatorList缓存
8. 重新渲染页面
9. 恢复视图状态
10. 恢复油墨清单状态

**关键代码：**

```javascript
eventBus._on("inkstatechanged", async evt => {
  // 保存状态
  const currentPage = this.page;
  const currentScale = this.pdfViewer.currentScale;

  // 重新加载文档
  await this.open({ url: this.url });

  // 同步配置到Worker
  await this.pdfDocument.updateColorFilterConfig(config);

  // 清除缓存并重新渲染
  // ...

  // 恢复状态
  this.page = currentPage;
  this.pdfViewer.currentScale = currentScale;
});
```

## 使用方式

### 初始化配置

```javascript
// PDF加载时初始化
ColorConverter.setColorFilterConfig({
  enabled: true,
  colors: {
    Cyan: true,
    Magenta: true,
    Yellow: true,
    Black: true,
  },
});
```

### 动态控制（通过UI）

**单个油墨控制：**

- 点击眼睛图标切换单个油墨的可见性
- 状态自动保存到当前页面

**CMYK组控制：**

- 点击CMYK组的眼睛图标可同时控制四个通道
- 状态自动保存到当前页面

**批量操作：**

- 点击"全部显示"按钮 - 显示当前页面的所有油墨
- 点击"全部隐藏"按钮 - 隐藏当前页面的所有油墨

**页面切换：**

- 切换页面时，自动恢复对应页面的油墨状态
- 每个页面的状态独立管理

### 程序化控制

```javascript
// 禁用颜色
ColorConverter.updateColorState("Magenta", false);
ColorConverter.updateColorState("Spot1", false);

// 添加新专色
ColorConverter.addSpotColor("Gold", true);

// 禁用过滤器
ColorConverter.setColorFilterConfig({ enabled: false });
```

### 获取状态

```javascript
const config = ColorConverter.getColorFilterConfig();
console.log("当前配置:", config);
```

## 状态持久化机制

### 数据结构

```javascript
// 按页面存储的油墨可见性状态
inkVisibilityState: Map<pageNumber, Map<inkName, visible>>

// 示例：
// page 1: { "CMYK": true, "青色": true, "洋红色": false, ... }
// page 2: { "CMYK": false, "青色": false, "洋红色": true, ... }
```

### 状态生命周期

1. **初始化**：页面首次渲染时，使用默认值（全部可见）
2. **用户操作**：点击眼睛图标时，保存到当前页面的状态Map
3. **页面切换**：从对应页面的状态Map恢复
4. **文档重新加载**：`inkVisibilityState` 保留，状态不丢失
5. **文档关闭**：状态清空（下次打开重新初始化）

### 状态恢复流程

```javascript
// 1. 页面切换时
_handlePageChange(evt) {
  this.currentPageNumber = evt.pageNumber;
  if (this.pageColorStates.has(newPageNumber)) {
    this._updateInkListFromCurrentPage(); // 恢复状态
  }
}

// 2. 恢复状态时
_updateInkListFromCurrentPage() {
  // 从当前页面的状态恢复
  visible: this._getInkVisibility(this.currentPageNumber, "CMYK", true)
}
```

## 兼容性说明

1. **向后兼容**: 原有代码无需修改，toRGB()默认使用过滤器

## 技术细节

### Worker线程同步

由于主线程和Worker线程的ColorConverter是独立实例，需要同步配置：

```javascript
// 主线程更新配置
ColorConverter.updateColorState("Cyan", false);

// 同步到Worker线程
await pdfDocument.updateColorFilterConfig({
  enabled: true,
  colors: { Cyan: false, ... }
});
```

### 缓存清除

文档重新加载后需要清除缓存：

```javascript
// 清除operatorList缓存
pageView.pdfPage.clearOperatorListCache();

// 清除对象缓存
pageView.pdfPage.objs.clear();

// 重置页面视图
pageView.reset();
```

### 防抖处理

避免频繁渲染，使用防抖机制：

```javascript
this.RENDER_DEBOUNCE_DELAY = 100; // 100ms防抖延迟
```
