# 🚀 快速测试指南：验证Bug修复和性能优化

## 📋 测试前准备

1. **确保服务器运行**

   ```bash
   npx gulp server
   ```

2. **打开浏览器**
   - 访问：http://localhost:8888/web/viewer.html
   - 打开开发者工具（F12）

3. **准备测试PDF**
   - 使用 `web/design.pdf`
   - 或任何包含CMYK图像的PDF

---

## ✅ 测试清单

### 测试1：图像过滤Bug修复验证 🔥 最重要

**目的**：验证CMYK图像通道过滤是否正常

#### 步骤：

1. 加载包含CMYK图像的PDF页面
2. 打开油墨清单（Ink List）面板
3. 点击 **Cyan（青色）** 通道的眼睛图标，隐藏该通道

**预期结果**：

- ✅ 图像仍然可见（不应该完全消失）
- ✅ 图像显示为洋红+黄色+黑色的叠加效果
- ✅ 青色成分消失

4. 再次点击 **Cyan** 通道的眼睛图标，显示该通道

**预期结果**：

- ✅ 图像恢复完整颜色（包含青色）
- ✅ 图像正常显示

#### 测试所有通道：

重复上述步骤，分别测试：

- [ ] Cyan（青色）
- [ ] Magenta（洋红色）
- [ ] Yellow（黄色）
- [ ] Black（黑色）

**每个通道都应该**：

- ✅ 隐藏时：图像仍可见，只是缺少该颜色成分
- ✅ 显示时：图像恢复该颜色成分

### 测试2：性能验证 ⚡

**目的**：验证性能优化是否有效

#### 步骤：

1. 打开Console面板
2. 输入并运行：
   ```javascript
   console.time("图像加载");
   ```
3. 加载大图像PDF或切换到包含大图像的页面
4. 等待渲染完成
5. 输入并运行：
   ```javascript
   console.timeEnd("图像加载");
   ```

**预期结果**：

- ✅ 100x100图像：< 200ms
- ✅ 500x500图像：< 2秒
- ✅ 1000x1000图像：< 10秒
- ✅ Console中无大量调试日志
- ✅ Network面板无fetch请求到7242端口

## 🐛 问题排查

### 如果图像仍然消失

1. **检查浏览器Console**
   - 看是否有JavaScript错误
   - 记录错误信息

2. **检查代码是否正确更新**
   - 确认 `src/core/icc_colorspace.js` 已更新
   - 第228-233行应该使用 `isVisible()` 方法

3. **清除缓存**
   - 按 Ctrl+F5 或 Cmd+Shift+R 强制刷新
   - 清除浏览器缓存

4. **重启服务器**
   - 停止 `npx gulp server`
   - 重新运行 `npx gulp server`

### 如果性能仍然很慢

1. **检查Console**
   - 看是否有大量日志输出
   - 如果有，说明调试代码未完全移除

2. **检查Network面板**
   - 看是否有fetch请求到7242端口
   - 如果有，说明调试代码未完全移除

3. **使用Performance面板**
   - 记录性能数据
   - 查看Scripting时间
   - 找出性能瓶颈
