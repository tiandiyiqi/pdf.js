# 问题已解决！

## 根本原因

**元素配置遗漏**：我们在 `viewer.js` 的 `toolbar` 配置中添加了 `editorGeoShapeColor`、`editorGeoShapeThickness`、`editorGeoShapeOpacity` 三个元素的引用，但是**忘记在 `annotationEditorParams` 配置中也添加它们**。

结果就是：

- ✅ 元素在 `toolbar` 中成功获取
- ❌ 元素没有传递给 `AnnotationEditorParams` 构造函数
- ❌ 事件监听器无法绑定
- ❌ 参数调整无效

## 修复内容

在 `web/viewer.js` 第 293-300 行，`annotationEditorParams` 配置对象中添加了三个元素：

```javascript
annotationEditorParams: {
  // ... 其他元素 ...
  editorInkColor: document.getElementById("editorInkColor"),
  editorInkThickness: document.getElementById("editorInkThickness"),
  editorInkOpacity: document.getElementById("editorInkOpacity"),
  // ✅ 新添加的三行
  editorGeoShapeColor: document.getElementById("editorGeoShapeColor"),
  editorGeoShapeThickness: document.getElementById("editorGeoShapeThickness"),
  editorGeoShapeOpacity: document.getElementById("editorGeoShapeOpacity"),
  editorStampAddImage: document.getElementById("editorStampAddImage"),
  // ...
}
```

## 经验教训

在 PDF.js 中添加新的 UI 参数时，需要在**两个地方**添加元素引用：

1. **`toolbar` 配置**：用于工具栏按钮和面板
2. **`annotationEditorParams` 配置**：用于参数管理器

这两个配置对象是独立的，必须都添加才能正常工作。
