# ✅ 快速测试检查清单

## 🚀 开始前

1. **启动服务器**

   ```bash
   npx gulp server
   ```

2. **刷新浏览器**
   - 按 `Ctrl+F5` (Windows) 或 `Cmd+Shift+R` (Mac)
   - 清除缓存并强制刷新

3. **打开开发者工具** (F12)
   - Console面板：检查是否有错误
   - Network面板：确认无fetch到7242端口

---

## 📋 核心测试（必须通过）

### ✅ 测试1：CMYK单通道过滤

**操作**：

1. 加载包含CMYK图像的PDF
2. 打开油墨清单（Ink List）
3. 点击隐藏 **Cyan** 通道

**预期**：

- [ ] 图像仍然可见（**不消失**）
- [ ] 图像显示为 洋红+黄色+黑色 的叠加效果
- [ ] 青色成分消失

4. 再次点击显示 **Cyan** 通道

**预期**：

- [ ] 图像恢复完整颜色（包含青色）

**重复测试**：Magenta, Yellow, Black 通道

- [ ] Magenta 通道：正常隐藏/显示
- [ ] Yellow 通道：正常隐藏/显示
- [ ] Black 通道：正常隐藏/显示

---

### ✅ 测试2：大图像降采样 + 过滤

**操作**：

1. 加载包含大尺寸CMYK图像的PDF（例如 > 2000x2000像素）
2. 等待图像加载和降采样
3. 打开油墨清单
4. 测试通道过滤

**预期**：

- [ ] 大图像加载速度快（< 10秒）
- [ ] 降采样后的图像可以正常应用颜色过滤
- [ ] 隐藏通道时，颜色变化正确
- [ ] 显示通道时，颜色恢复正确

---

### ✅ 测试3：JPEG压缩CMYK图像

**操作**：

1. 加载包含JPEG压缩CMYK图像的PDF
2. 测试通道过滤

**预期**：

- [ ] JPEG压缩图像加载正常
- [ ] 颜色过滤工作正常
- [ ] 与未压缩CMYK图像行为一致

---

### ✅ 测试4：专色验证（回归测试）

**操作**：

1. 加载包含专色的PDF
2. 在油墨清单中找到专色
3. 隐藏/显示专色

**预期**：

- [ ] 专色隐藏：专色内容变白色
- [ ] 专色显示：专色内容正常显示
- [ ] 二元过滤（全有或全无）工作正常

---

## 🔍 性能检查

### Console面板

**检查**：

- [ ] 无大量日志输出
- [ ] 无JavaScript错误
- [ ] 无fetch请求到 `http://127.0.0.1:7242`

### Network面板

**检查**：

- [ ] 无异常网络请求
- [ ] 图像加载速度快

### 时间测试

在Console中运行：

```javascript
console.time("图像加载");
// 切换到包含大图像的页面
console.timeEnd("图像加载");
```

**预期**：

- [ ] 100x100 图像：< 200ms
- [ ] 1000x1000 图像：< 10秒
- [ ] 2000x2000 图像：< 30秒

---

## 🎯 测试结果

### 通过标准

- ✅ **所有核心测试通过**：功能正常
- ✅ **性能检查通过**：无性能问题
- ✅ **无Console错误**：代码质量良好

### 如果测试失败

1. **图像仍然消失**
   - 检查是否刷新了浏览器
   - 检查Console是否有错误
   - 联系开发人员

2. **性能很慢**
   - 检查Network面板是否有异常请求
   - 检查Console是否有大量日志
   - 联系开发人员

3. **颜色不正确**
   - 截图并描述问题
   - 提供PDF文件（如果可以）
   - 联系开发人员
