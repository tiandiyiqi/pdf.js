# 矩形交互功能测试指南

## 修改摘要

已成功实现矩形编辑器的完整交互功能，包括以下修改：

### 1. 修改文件列表

1. **`src/display/editor/draw.js`** (第338-343行)
   - 移除了 `commit()` 方法中的 `disableEditing()` 调用
   - 使矩形创建后保持可交互状态

2. **`src/display/editor/rectangle.js`** (第205-208行)
   - 为 `toolbarButtons` getter 添加颜色选择器
   - 返回 `BasicColorPicker` 实例

3. **`src/display/editor/ink.js`** (第192-197行)
   - 添加 `commit()` 方法重写
   - 保持 InkEditor 原有行为（绘制完成后禁用编辑）

4. **`src/display/editor/color_picker.js`** (第327-330行)
   - 为 `BasicColorPicker` 添加 `rectangle` 类型的 l10n 键
   - 修复颜色选择器无法正确初始化的问题

5. **`l10n/en-US/viewer.ftl`** 和 **`l10n/zh-CN/viewer.ftl`**
   - 添加矩形颜色选择器的本地化字符串
   - `pdfjs-editor-color-picker-rectangle-input`

### 2. 核心问题解决

**问题根源**：

- `DrawingEditor.commit()` 调用 `disableEditing()`
- 添加 `.disabled` CSS 类，设置 `pointer-events: none`
- 导致矩形完全无法接收鼠标事件

**解决方案**：

- 移除 `DrawingEditor.commit()` 中的 `disableEditing()` 调用
- 为 InkEditor 单独重写 `commit()` 保持原有行为
- RectangleEditor 继承修改后的行为，保持可交互

## 故障排查

### 问题 1: 矩形创建后仍无法交互

**可能原因**：

- 构建未完成或未生效
- 浏览器缓存未清除

**解决方法**：

1. 确认 `npx gulp generic` 构建成功
2. 硬刷新浏览器（Ctrl+Shift+R 或 Cmd+Shift+R）
3. 检查浏览器控制台是否有错误

### 问题 2: 工具栏没有颜色按钮

**可能原因**：

- `BasicColorPicker` 导入失败
- `toolbarButtons` getter 未正确修改

**解决方法**：

1. 检查 `src/display/editor/rectangle.js` 第25行是否导入了 `BasicColorPicker`
2. 检查第205-208行的 `toolbarButtons` getter 是否返回颜色选择器

### 问题 3: InkEditor 行为异常

**可能原因**：

- `commit()` 方法重写有误

**解决方法**：

1. 检查 `src/display/editor/ink.js` 是否添加了 `commit()` 方法
2. 确认方法中调用了 `this.disableEditing()`
