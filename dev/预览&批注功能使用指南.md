## 功能概述

### 1. 几何工具（矩形/圆形/箭头）

**功能描述**：在PDF页面上绘制几何图形（矩形、圆形、箭头），支持编辑、调整大小、移动等操作。

**核心库位置**：

- `src/display/editor/rectangle.js` - 矩形编辑器
- `src/display/editor/circle.js` - 圆形编辑器
- `src/display/editor/arrow.js` - 箭头编辑器
- `src/display/editor/annotation_editor_layer.js` - 编辑器层管理

**查看器层位置**：

- `web/viewer.html` - UI按钮
- `web/toolbar.js` - 工具栏事件处理

---

### 2. 颜色过滤器（分色预览）

**功能描述**：动态控制CMYK通道和专色的显示/隐藏，实现分色预览功能。

**核心库位置**：

- `src/core/color_converter.js` - 颜色转换和过滤逻辑

**查看器层位置**：

- `web/pdf_ink_list_viewer.js` - 油墨清单UI组件
- `web/app.js` - 文档重新加载逻辑

---

### 3. 叠印预览

**功能描述**：预览CMYK颜色空间的叠印效果，显示颜色叠加后的实际效果。

**核心库位置**：

- `src/display/canvas.js` - Canvas渲染器（`CanvasGraphics`类）

**查看器层位置**：

- `web/app.js` - 叠印选项UI控制
- `web/pdf_page_view.js` - 页面视图管理

---

## 核心库与查看器层区别

### 架构分层

PDF.js采用三层架构：

```
┌─────────────────────────────────────┐
│  web/ (查看器层)                     │
│  - UI组件、工具栏、事件处理          │
│  - 完整查看器界面                    │
└─────────────────────────────────────┘
           ↓ 基于
┌─────────────────────────────────────┐
│  src/display/ (显示渲染层)          │
│  - 页面渲染、Canvas操作             │
│  - 编辑器、注释层                    │
└─────────────────────────────────────┘
           ↓ 基于
┌─────────────────────────────────────┐
│  src/core/ (核心解析层)             │
│  - PDF文件结构解析                   │
│  - 颜色转换、字体处理                │
└─────────────────────────────────────┘
```

### 核心库导出

从 `src/pdf.js` 可以看到，以下类已导出到 `pdfjsLib`：

- ✅ `ColorConverter` - 颜色转换器（包含颜色过滤功能）
- ✅ `AnnotationEditorLayer` - 编辑器层（包含几何工具）
- ✅ 叠印预览通过渲染API参数传递，无需额外导出

## 几何工具使用

### 基本使用

```javascript
import * as pdfjsLib from "pdf.mjs";

// 配置Worker
pdfjsLib.GlobalWorkerOptions.workerSrc = "pdf.worker.mjs";

// 加载PDF文档
const pdfDoc = await pdfjsLib.getDocument("document.pdf").promise;
const page = await pdfDoc.getPage(1);

// 创建容器元素
const container = document.createElement("div");
container.style.position = "relative";
container.style.width = "800px";
container.style.height = "600px";
document.body.appendChild(container);

// 创建编辑器层
const editorLayer = new pdfjsLib.AnnotationEditorLayer({
  div: container,
  uiManager: null, // 核心库集成时可为null
  pageIndex: 0, // 页码（从0开始）
  l10n: null, // 本地化对象（可选）
  accessibilityManager: null, // 可访问性管理器（可选）
  annotationStorage: null, // 注释存储（可选）
  isLTR: true, // 从左到右布局
});

// 设置几何工具模式
editorLayer.setMode(pdfjsLib.AnnotationEditorType.GEOSHAPE);

// 设置当前工具类型（矩形/圆形/箭头）
// 注意：需要在查看器层通过事件设置，核心库中需要手动设置
// 可以通过修改 annotation_editor_layer.js 的 #currentGeoShapeType 属性
```

### 工具类型设置

由于工具类型切换机制在查看器层实现，核心库集成时需要手动设置：

```javascript
// 方式1：直接修改内部属性（需要访问私有属性）
editorLayer._currentGeoShapeType = "geoshapeRect"; // 矩形
// 或
editorLayer._currentGeoShapeType = "geoshapeCirc"; // 圆形
// 或
editorLayer._currentGeoShapeType = "geoshapeArrow"; // 箭头

// 方式2：通过事件系统（如果实现了事件总线）
// 需要实现类似查看器层的事件机制
```

### 绘制流程

```javascript
// 1. 用户点击页面开始绘制
// AnnotationEditorLayer 会自动处理 pointerdown 事件

// 2. 拖动鼠标调整图形大小
// 系统自动更新图形预览

// 3. 松开鼠标完成绘制
// 自动创建编辑器实例并进入编辑模式
```

### 编辑器操作

```javascript
// 获取所有编辑器
const editors = editorLayer.getEditors();

// 选中编辑器
editors[0].select();

// 删除编辑器
editors[0].remove();

// 序列化编辑器数据
const serialized = editors[0].serialize();
```

### 完整示例

```javascript

  // 加载PDF
  const pdfDoc = await pdfjsLib.getDocument("document.pdf").promise;
  const page = await pdfjsLib.getPage(1);

  // 创建页面容器
  const container = document.getElementById("pdf-container");

  // 创建编辑器层

    div: container,

    pageIndex: 0,

    isLTR: true,
  });

  // 设置几何工具模式
  editorLayer.setMode(pdfjsLib.AnnotationEditorType.GEOSHAPE);

  // 设置工具类型（需要访问私有属性或实现事件机制）
  editorLayer._currentGeoShapeType = "geoshapeRect";

  return editorLayer;
}
```

## 颜色过滤器使用

### 基本使用

```javascript
import * as pdfjsLib from "pdf.mjs";

// ColorConverter 已导出到 pdfjsLib
const ColorConverter = pdfjsLib.ColorConverter;

// 设置颜色过滤器配置
ColorConverter.setColorFilterConfig({
  enabled: true,
  colors: {
    Cyan: true, // 青色可见
    Magenta: false, // 洋红色隐藏
    Yellow: true, // 黄色可见
    Black: true, // 黑色可见
  },
});

// 更新单个颜色状态
ColorConverter.updateColorState("Magenta", true); // 显示洋红色
ColorConverter.updateColorState("Cyan", false); // 隐藏青色

// 添加专色
ColorConverter.addSpotColor("Gold", true); // 添加金色专色，默认可见
ColorConverter.addSpotColor("Silver", false); // 添加银色专色，默认隐藏

// 获取当前配置
const config = ColorConverter.getColorFilterConfig();
console.log(config);
```

### 动态控制

```javascript
// 禁用颜色过滤器
ColorConverter.setColorFilterConfig({ enabled: false });

// 重新启用
ColorConverter.setColorFilterConfig({ enabled: true });

// 批量更新颜色状态
const colors = ["Cyan", "Magenta", "Yellow", "Black"];
colors.forEach(color => {
  ColorConverter.updateColorState(color, true);
});
```

### 与渲染集成

颜色过滤器会自动应用到PDF渲染过程中：

```javascript
import * as pdfjsLib from "pdf.mjs";

pdfjsLib.GlobalWorkerOptions.workerSrc = "pdf.worker.mjs";

async function renderWithColorFilter() {
  // 设置颜色过滤器
  pdfjsLib.ColorConverter.setColorFilterConfig({
    enabled: true,
    colors: {
      Cyan: true,
      Magenta: false, // 隐藏洋红色
      Yellow: true,
      Black: true,
    },
  });

  // 加载PDF
  const pdfDoc = await pdfjsLib.getDocument("document.pdf").promise;
  const page = await pdfDoc.getPage(1);

  // 渲染页面（颜色过滤器会自动应用）
  const viewport = page.getViewport({ scale: 1.5 });
  const canvas = document.createElement("canvas");
  canvas.height = viewport.height;
  canvas.width = viewport.width;

  const ctx = canvas.getContext("2d");
  await page.render({
    canvasContext: ctx,
    viewport: viewport,
  }).promise;

  document.body.appendChild(canvas);
}
```

### 事件监听

```javascript
// 监听颜色状态变化事件（如果实现了事件系统）
ColorConverter.addEventListener("colorstatechanged", event => {
  console.log("颜色状态变化:", event.colorName, event.visible);
  // 重新渲染页面
  renderPage();
});
```

### 完整示例

```javascript
import * as pdfjsLib from "pdf.mjs";

pdfjsLib.GlobalWorkerOptions.workerSrc = "pdf.worker.mjs";

class ColorFilterController {
  constructor() {
    this.pdfDoc = null;
    this.currentPage = 1;
  }

  async loadPDF(url) {
    this.pdfDoc = await pdfjsLib.getDocument(url).promise;
    await this.renderPage(this.currentPage);
  }

  async renderPage(pageNum) {
    const page = await this.pdfDoc.getPage(pageNum);
    const viewport = page.getViewport({ scale: 1.5 });

    const canvas = document.getElementById("pdf-canvas");
    canvas.height = viewport.height;
    canvas.width = viewport.width;

    const ctx = canvas.getContext("2d");
    await page.render({
      canvasContext: ctx,
      viewport: viewport,
    }).promise;

    this.currentPage = pageNum;
  }

  toggleColor(colorName) {
    const config = pdfjsLib.ColorConverter.getColorFilterConfig();
    const currentState = config.colors.get(colorName) || false;
    pdfjsLib.ColorConverter.updateColorState(colorName, !currentState);
    // 重新渲染以应用变化
    this.renderPage(this.currentPage);
  }
}

// 使用示例
const controller = new ColorFilterController();
await controller.loadPDF("document.pdf");

// 切换颜色显示
document.getElementById("toggle-cyan").addEventListener("click", () => {
  controller.toggleColor("Cyan");
});
```

## 叠印预览使用

### 基本使用

叠印预览功能通过 `page.render()` 方法的 `renderContext` 参数传递：

```javascript
import * as pdfjsLib from "pdf.mjs";

pdfjsLib.GlobalWorkerOptions.workerSrc = "pdf.worker.mjs";

async function renderWithOverprint() {
  // 加载PDF
  const pdfDoc = await pdfjsLib.getDocument("document.pdf").promise;
  const page = await pdfDoc.getPage(1);

  // 设置canvas尺寸
  const viewport = page.getViewport({ scale: 1.5 });
  const canvas = document.createElement("canvas");
  canvas.height = viewport.height;
  canvas.width = viewport.width;

  // 渲染到canvas（启用叠印预览）
  const ctx = canvas.getContext("2d");
  const renderContext = {
    canvasContext: ctx,
    viewport: viewport,
    overprintOption: true, // 启用叠印预览
  };

  await page.render(renderContext).promise;

  document.body.appendChild(canvas);
}
```

### 动态切换

```javascript
let overprintEnabled = false;

async function renderPage(pageNum, enableOverprint) {
  const page = await pdfDoc.getPage(pageNum);
  const viewport = page.getViewport({ scale: 1.5 });

  const canvas = document.getElementById("pdf-canvas");
  canvas.height = viewport.height;
  canvas.width = viewport.width;

  const ctx = canvas.getContext("2d");
  const renderContext = {
    canvasContext: ctx,
    viewport: viewport,
    overprintOption: enableOverprint, // 动态控制叠印选项
  };

  await page.render(renderContext).promise;
}

// 切换叠印预览
document.getElementById("overprint-toggle").addEventListener("change", e => {
  overprintEnabled = e.target.checked;
  renderPage(currentPage, overprintEnabled);
});
```

### 完整示例

```javascript
import * as pdfjsLib from "pdf.mjs";

pdfjsLib.GlobalWorkerOptions.workerSrc = "pdf.worker.mjs";

class OverprintViewer {
  constructor() {
    this.pdfDoc = null;
    this.currentPage = 1;
    this.overprintEnabled = false;
  }

  async loadPDF(url) {
    this.pdfDoc = await pdfjsLib.getDocument(url).promise;
    await this.render();
  }

  async render() {
    const page = await this.pdfDoc.getPage(this.currentPage);
    const viewport = page.getViewport({ scale: 1.5 });

    const canvas = document.getElementById("pdf-canvas");
    canvas.height = viewport.height;
    canvas.width = viewport.width;

    const ctx = canvas.getContext("2d");
    const renderContext = {
      canvasContext: ctx,
      viewport: viewport,
      overprintOption: this.overprintEnabled,
    };

    await page.render(renderContext).promise;
  }

  toggleOverprint() {
    this.overprintEnabled = !this.overprintEnabled;
    this.render();
  }

  nextPage() {
    if (this.currentPage < this.pdfDoc.numPages) {
      this.currentPage++;
      this.render();
    }
  }

  prevPage() {
    if (this.currentPage > 1) {
      this.currentPage--;
      this.render();
    }
  }
}

// 使用示例
const viewer = new OverprintViewer();
await viewer.loadPDF("document.pdf");

document.getElementById("overprint-btn").addEventListener("click", () => {
  viewer.toggleOverprint();
});
```

## API参考

### ColorConverter API

#### `setColorFilterConfig(config)`

设置颜色过滤器配置。

**参数**：

- `config.enabled` (boolean) - 是否启用过滤器
- `config.colors` (Object) - 颜色状态对象，格式：`{ "Cyan": true, "Magenta": false, ... }`

**示例**：

```javascript
pdfjsLib.ColorConverter.setColorFilterConfig({
  enabled: true,
  colors: {
    Cyan: true,
    Magenta: false,
    Yellow: true,
    Black: true,
  },
});
```

#### `getColorFilterConfig()`

获取当前颜色过滤器配置。

**返回**：配置对象

**示例**：

```javascript
const config = pdfjsLib.ColorConverter.getColorFilterConfig();
console.log(config.enabled); // true
console.log(config.colors); // Map对象
```

#### `updateColorState(colorName, visible)`

更新单个颜色的可见性状态。

**参数**：

- `colorName` (string) - 颜色名称（如 "Cyan", "Magenta", "Yellow", "Black"）
- `visible` (boolean) - 是否可见

**示例**：

```javascript
pdfjsLib.ColorConverter.updateColorState("Cyan", false);
```

#### `addSpotColor(spotName, visible)`

添加专色。

**参数**：

- `spotName` (string) - 专色名称
- `visible` (boolean) - 是否可见

**示例**：

```javascript
pdfjsLib.ColorConverter.addSpotColor("Gold", true);
```

### AnnotationEditorLayer API

#### `new AnnotationEditorLayer(params)`

创建编辑器层实例。

**参数**：

- `params.div` (HTMLElement) - 容器元素
- `params.uiManager` (Object|null) - UI管理器（核心库集成时可传null）
- `params.pageIndex` (number) - 页码索引（从0开始）
- `params.l10n` (Object|null) - 本地化对象（可选）
- `params.accessibilityManager` (Object|null) - 可访问性管理器（可选）
- `params.annotationStorage` (Object|null) - 注释存储（可选）
- `params.isLTR` (boolean) - 是否从左到右布局

#### `setMode(mode)`

设置编辑器模式。

**参数**：

- `mode` (number) - 编辑器类型，如 `pdfjsLib.AnnotationEditorType.GEOSHAPE`

#### `getEditors()`

获取所有编辑器实例。

**返回**：编辑器数组

---

### 渲染API

#### `page.render(renderContext)`

渲染PDF页面到Canvas。

**参数**：

- `renderContext.canvasContext` (CanvasRenderingContext2D) - Canvas上下文
- `renderContext.viewport` (PageViewport) - 页面视口
- `renderContext.overprintOption` (boolean) - 是否启用叠印预览

**返回**：Promise，渲染任务

**示例**：

```javascript
const renderContext = {
  canvasContext: ctx,
  viewport: viewport,
  overprintOption: true,
};

await page.render(renderContext).promise;
```

## 注意事项

### 1. Worker配置

使用核心库时必须配置Worker路径：

```javascript
pdfjsLib.GlobalWorkerOptions.workerSrc = "pdf.worker.mjs";
```

### 2. 颜色过滤器同步

颜色过滤器配置需要在主线程和Worker线程之间同步。如果使用Worker，需要：

```javascript
// 主线程更新配置
pdfjsLib.ColorConverter.setColorFilterConfig(config);

// 同步到Worker线程（如果使用Worker）
await pdfDocument.updateColorFilterConfig(config);
```

### 3. 几何工具类型设置

几何工具类型切换机制在查看器层实现，核心库集成时需要手动设置：

```javascript
// 需要访问私有属性
editorLayer._currentGeoShapeType = "geoshapeRect";
```

或者实现自己的事件系统来管理工具类型。

### 4. 页面重新渲染

修改颜色过滤器或叠印选项后，需要重新渲染页面才能看到效果：

```javascript
// 更新颜色过滤器
pdfjsLib.ColorConverter.updateColorState("Cyan", false);

// 重新渲染
await renderPage(currentPage);
```

### 5. 编辑器层生命周期

编辑器层需要与PDF页面生命周期同步：

```javascript
// 页面切换时
this.currentPage = newPage;
this.editorLayer.pageIndex = newPage - 1;
await this.render();
```

## 总结

三种功能的核心逻辑都在核心库中实现，可以通过核心库API直接调用：

1. **几何工具**：通过 `AnnotationEditorLayer` 类使用
2. **颜色过滤器**：通过 `ColorConverter` 类使用
3. **叠印预览**：通过 `page.render()` 的 `renderContext` 参数使用

查看器层（`web/`）仅提供UI界面，核心库集成时可以完全自定义UI。

## 完整查看器使用

完整查看器（`web/viewer.html`）提供了开箱即用的PDF查看器界面，包含工具栏、侧边栏、搜索等完整功能。三种定制功能都已集成到完整查看器中。

### 集成方式

#### 方式1：iframe集成（推荐）

最简单的方式是使用iframe嵌入完整查看器：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>PDF查看器集成</title>
    <style>
      .viewer-container {
        width: 100%;
        height: 100vh;
        border: none;
      }
      .controls {
        padding: 10px;
        background: #f5f5f5;
        border-bottom: 1px solid #ddd;
      }
    </style>
  </head>
  <body>
    <div class="controls">
      <h3>PDF查看器控制</h3>
      <input
        type="text"
        id="pdf-url"
        placeholder="PDF文件URL"
        value="document.pdf"
      />
      <button id="load-pdf">加载PDF</button>
      <button id="toggle-overprint">切换叠印</button>
    </div>

    <iframe id="pdf-viewer" class="viewer-container"></iframe>

    <script>
      const pdfViewer = document.getElementById("pdf-viewer");
      const pdfUrlInput = document.getElementById("pdf-url");
      const loadPdfBtn = document.getElementById("load-pdf");
      const toggleOverprintBtn = document.getElementById("toggle-overprint");

      let overprintEnabled = true;

      // 加载PDF
      function loadPdf() {
        const pdfUrl = pdfUrlInput.value;
        const encodedUrl = encodeURIComponent(pdfUrl);
        // 通过URL参数传递PDF路径和叠印选项
        pdfViewer.src = `/web/viewer.html?file=${encodedUrl}&overprintOption=${overprintEnabled}`;
      }

      // 切换叠印预览
      function toggleOverprint() {
        overprintEnabled = !overprintEnabled;
        // 通过postMessage发送消息到iframe
        pdfViewer.contentWindow.postMessage(
          {
            type: "setOverprintOption",
            enabled: overprintEnabled,
          },
          "*"
        );
      }

      // 监听iframe消息
      window.addEventListener("message", event => {
        if (event.data && event.data.type === "overprintOptionChanged") {
          overprintEnabled = event.data.enabled;
          console.log("叠印状态已同步:", overprintEnabled);
        }
      });

      loadPdfBtn.addEventListener("click", loadPdf);
      toggleOverprintBtn.addEventListener("click", toggleOverprint);

      // 页面加载时自动加载PDF
      loadPdf();
    </script>
  </body>
</html>
```

### URL参数配置

完整查看器支持通过URL参数配置：

```html
<!-- 基本用法 -->
```

**支持的URL参数**：

- `file` - PDF文件URL（必需）
- `overprintOption` - 叠印预览开关（`true`/`false`）

- `zoom` - 初始缩放级别（数字或 `page-fit`、`page-width`）
- `toolbar` - 是否显示工具栏（`0`=隐藏，`1`=显示）
- `sidebar` - 是否显示侧边栏（`0`=隐藏，`1`=显示）

```html
      const config = {
        defaultPdfUrl: "document.pdf",
        viewerPath: "/web/viewer.html",
      };

      const MESSAGE_TYPES = {
        SET_OVERPRINT_OPTION: "setOverprintOption",
        OVERPRINT_OPTION_CHANGED: "overprintOptionChanged",
```

### 查看器API

完整查看器提供了全局对象 `PDFViewerApplication`，可以通过它访问查看器的各种功能：

```javascript
// 等待查看器初始化完成
await PDFViewerApplication.initialized;

// 打开PDF文档
PDFViewerApplication.open({
  url: "document.pdf",

const pdfDoc = PDFViewerApplication.pdfDocument;

// 获取事件总线
const eventBus = PDFViewerApplication.eventBus;

eventBus.on("pagesloaded", () => {
  console.log("页面已加载");

// 设置叠印选项
PDFViewerApplication.setOverprintOption(true);

// 获取当前页码
const currentPage = PDFViewerApplication.page;

PDFViewerApplication.page = 5;
```

```javascript
const eventBus = PDFViewerApplication.eventBus;
```

```javascript
// 设置叠印选项
```

### 注意事项

1. **iframe通信安全**：使用 `postMessage` 时，建议指定具体的 `targetOrigin`，而不是使用 `'*'`。

2. **查看器初始化**：确保在查看器初始化完成后再调用API：

   ```javascript
   await PDFViewerApplication.initialized;
   // 现在可以安全地调用API
   ```

3. **颜色过滤器重新加载**：颜色过滤器状态变化会自动触发文档重新加载，这是正常行为。

4. **几何工具模式**：需要先设置编辑器模式为 `GEOSHAPE`，然后才能使用几何工具。

5. **URL参数编码**：通过URL传递PDF路径时，记得使用 `encodeURIComponent` 编码。
