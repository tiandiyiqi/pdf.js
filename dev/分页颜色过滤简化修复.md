# 分页颜色过滤简化修复

## 问题描述

当油墨列表的清单变化触发颜色过滤功能时，系统错误地执行了**全局渲染**而非**仅当前页面的局部渲染**。

具体表现：

- 在第1页关闭某个颜色，所有页面的该颜色都消失
- 页面切换时出现闪烁
- 分页加载机制受到干扰

## 根本原因

在 `web/pdf_viewer.js` 的 `set colorFilterConfigPromise()` 方法中：

```javascript
set colorFilterConfigPromise(promise) {
  // ...
  this.refresh(false, { colorFilterConfigPromise: promise });
  // ❌ refresh() 会遍历所有页面并调用 update()
}
```

`refresh()` 方法会遍历 `this._pages`（所有页面），对每个页面调用 `update()`，导致：

1. **全局刷新** - 所有页面都重新渲染
2. **页面闪烁** - 多次不必要的渲染
3. **状态混乱** - 不同页面的状态相互干扰

## 修复方案（极简）

**文件**：`web/pdf_viewer.js`

**位置**：`set colorFilterConfigPromise()` 方法（第2071-2084行）

**修改前**：

```javascript
set colorFilterConfigPromise(promise) {
  if (!(promise instanceof Promise)) {
    throw new Error(`Invalid colorFilterConfigPromise: ${promise}`);
  }
  if (!this.pdfDocument) {
    return;
  }
  this._colorFilterConfigPromise = promise;

  this.refresh(false, { colorFilterConfigPromise: promise }); // ❌ 全局刷新
}
```

**修改后**：

```javascript
set colorFilterConfigPromise(promise) {
  if (!(promise instanceof Promise)) {
    throw new Error(`Invalid colorFilterConfigPromise: ${promise}`);
  }
  if (!this.pdfDocument) {
    return;
  }
  this._colorFilterConfigPromise = promise;

  // 只刷新当前页面，避免全局刷新导致闪烁
  const currentPageView = this._pages[this._currentPageNumber - 1];
  if (currentPageView) {
    currentPageView.update({ colorFilterConfigPromise: promise }); // ✅ 只刷新当前页
  }
}
```

## 为什么这样就够了？

1. **油墨清单本来就是分页的**
   - `PDFInkListViewer` 已经按页面维护油墨列表
   - `inkVisibilityState` 已经按页面存储可见性状态
   - `pageColorStates` 已经按页面存储颜色数据

2. **ColorFilterConfig 是全局的，但应用是局部的**
   - `ColorFilterConfig` 实例是全局共享的（这是正确的）
   - 当用户点击颜色时，更新全局 `ColorFilterConfig`
   - 触发 `colorfilterconfig` 事件，只刷新**当前页面**

3. **页面切换时自动处理**
   - 用户切换到新页面时，`PDFInkListViewer` 自动更新油墨列表
   - 油墨列表从该页面的持久化状态恢复可见性
   - 用户在新页面的操作只影响新页面

## 工作流程

### 场景1：在第1页关闭Cyan

```
用户点击Cyan → 更新全局ColorFilterConfig → 触发colorfilterconfig事件
→ 只刷新第1页 → 第1页的Cyan消失 → 其他页面不受影响 ✅
```

### 场景2：切换到第2页

```
用户切换页面 → PDFInkListViewer检测到pagechanging事件
→ 从第2页的持久化状态恢复油墨列表 → 第2页显示自己的颜色配置 ✅
```

### 场景3：在第2页关闭Yellow

```
用户点击Yellow → 更新全局ColorFilterConfig → 触发colorfilterconfig事件
→ 只刷新第2页 → 第2页的Yellow消失 → 第1页保持原状 ✅
```

## 技术细节

### 关键理解

- **全局配置 + 局部应用 = 分页效果**
- 不需要为每个页面创建独立的 `ColorFilterConfig`
- 不需要在页面切换时手动应用配置
- 只需要**阻止全局刷新**，改为**局部刷新**

### 数据流

```
用户操作 → ColorFilterConfig（全局）→ colorfilterconfig事件
→ PDFViewer.colorFilterConfigPromise setter → 只更新当前页面
```

## 修改的文件

只修改了一个文件：

- **web/pdf_viewer.js** - 将 `this.refresh()` 改为只更新当前页面

## 测试场景

1. **单页面颜色切换**：在第1页关闭Cyan，只有第1页的Cyan消失
2. **多页面独立配置**：第1页关闭Cyan，第2页的Cyan仍然显示
3. **页面切换保持状态**：在第1页关闭Cyan，切到第2页再切回来，第1页的Cyan仍然关闭
4. **无闪烁**：切换颜色和切换页面都不会出现闪烁
